# 갈림길 인생

친구들에게 링크를 보내 각자의 컴퓨터(PC 브라우저)에서 함께 하는 **한국어 턴제 인생 보드게임**. 2~12명, 수익화 없음.

주사위로 이동하고, 칸마다 일어나는 사건에서 선택하고, 능력 판정으로 결과가 갈립니다.
성장기 → 진로 → 성인 전반 → 중간 점검 → 성인 후반 → 은퇴 → 최종 정산까지 서로 다른 삶을 살아 보세요.

- 규칙: [docs/RULES.md](docs/RULES.md)
- 참고 자료 조사 기록: [docs/RESEARCH.md](docs/RESEARCH.md)
- 진행 상황·남은 작업: [docs/PROGRESS.md](docs/PROGRESS.md)

## 실행 (Windows CMD)

Node.js 20 이상만 있으면 됩니다. 외부 패키지를 설치하지 않습니다.

```bat
cd /d D:\game_create
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다.

| 명령 | 설명 |
|---|---|
| `npm start` | 서버 실행 (기본 포트 3000) |
| `npm run dev` | 파일이 바뀌면 자동 재시작 |
| `npm test` | 규칙·서버 자동 테스트 (2/4/8/12인 완주, 저장/복구, 12 클라이언트 동기화 등) |
| `npm run lint` | 구문·UTF-8 인코딩·콘텐츠 데이터 무결성 검사 |
| `npm run check` | lint + test |
| `node scripts\bots.js http://localhost:3000 <방ID> <비밀번호> 3` | 테스트용 봇 3명 참가 |

### 환경 변수

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 서버 포트 |
| `HOST` | 0.0.0.0 | 바인딩 주소 |
| `DATA_DIR` | `./data` | 방·게임 저장 폴더 (배포 시 영구 디스크 경로) |
| `TRUST_PROXY` | (없음) | 프록시 뒤에서 실행할 때 `1` (요청 제한에 실제 IP 사용) |

CMD 예: `set PORT=8080 && set DATA_DIR=D:\glg-data && npm start`

## 방 만들기와 초대

1. 첫 화면에서 닉네임·방 비밀번호·정원(2~12, 기본 8)·게임 길이를 정하고 **방 만들기**
2. 대기실의 **링크 복사**로 초대 링크를 보내고, 비밀번호는 따로 알려 주기
3. 친구는 링크에서 닉네임과 비밀번호를 입력해 참가 → **준비 완료**
4. 방장은 정원 변경, 입장 잠금, 내보내기, 방장 넘기기, 설정 변경 후 **게임 시작** (2명 이상, 모두 준비)

## 게임 길이 설정

대기실/방 만들기 화면에서:
- 프리셋: 짧은 여정 / 기본 여정 / 긴 여정 / 직접 설정 (실제 값이 화면에 그대로 표시되고 개별 수정 가능)
- 시작 단계: 성장기부터 / 성인기부터(배경·첫 직업을 동시에 고르는 준비 단계)
- 단계별 길이: 성장기 8~30칸, 성인 전반·후반 10~40칸 (1인 예상 턴 수 표시)
- 콘텐츠: 추가 진로, 특별 지역(바람섬), 공동 사건, 확장 사건
- 진행 속도·반복 연출 생략·선택 시간 제한(없음/30/60/120초)
- 인원과 설정으로 계산한 예상 플레이타임 범위 표시. 게임 중에는 실제 턴 소요 시간으로 남은 시간을 다시 계산

## 저장과 이어하기

- 모든 행동은 서버에 즉시 저장됩니다(`DATA_DIR/rooms/<방ID>.json`, 원자적 쓰기).
- 창을 닫거나 새로고침해도 **같은 브라우저로 같은 링크**를 열면 자기 자리로 돌아옵니다.
- 다른 컴퓨터에서는 게임 메뉴의 **내 복구 코드**를 첫 화면 "다른 컴퓨터에서 이어하기"에 붙여 넣습니다.
- 서버를 재시작해도 진행 중인 게임(난수 상태·대기 중 선택·기록 포함)이 그대로 복구됩니다.
- 방 보관 기간(마지막 활동 기준, 접속자가 없을 때 삭제): 대기실 24시간, 진행 중 30일, 종료 후 3일.

## 배포

### ChatGPT Sites

`npm ci`와 `npm run build:sites`로 배포 파일을 생성합니다. Sites의 서버는
D1에 방을 저장하고, 게임 화면은 약 1.2초 간격으로 방 상태를 확인합니다.
로컬 서버와 Sites의 저장 공간은 별도입니다.

Sites를 초대 방식으로 공유하는 경우 친구가 초대받은 ChatGPT 계정으로
로그인해야 합니다. 게임에서는 방 초대 링크와 방 비밀번호를 사용합니다.

서버 하나(Node, 외부 의존성 없음)가 정적 파일·API·실시간 동기화(SSE)를 모두 처리하므로
**영구 디스크가 있는 컨테이너 호스팅 1개**면 됩니다. HTTPS는 호스팅이 제공합니다.

### A. Fly.io (권장: 영구 볼륨 + 항상 켜짐)
`fly.toml`, `Dockerfile` 포함. 카드 등록이 필요하며 소액 과금(작은 VM + 1GB 볼륨)이 발생할 수 있습니다.
```bat
fly auth login
fly launch --no-deploy --copy-config --name <원하는-앱-이름>
fly volumes create glg_data --size 1 --region nrt
fly deploy
```
업데이트: `fly deploy`

### B. Render (유료 Starter + 디스크)
`render.yaml` 블루프린트 포함. GitHub 저장소를 연결하면 푸시할 때마다 자동 배포됩니다.
무료 인스턴스는 디스크가 없고 잠들면 저장이 사라지므로 이 게임에는 맞지 않습니다.

### C. 내 PC에서 서버 + Cloudflare 빠른 터널 (무료, 계정 불필요)
게임하는 동안 내 PC를 켜 두면 됩니다. 저장은 내 PC 디스크에 남습니다.
```bat
npm start
cloudflared tunnel --url http://localhost:3000
```
출력된 `https://….trycloudflare.com` 주소를 친구에게 보냅니다(실행할 때마다 주소가 바뀌므로 저장된 게임 링크도 새 주소로 바꿔 열어야 합니다: `https://새주소/r/<방ID>`).

## 구조

```
game/      규칙 엔진·콘텐츠·설정 (서버와 브라우저가 함께 사용)
server/    HTTP 서버, 방 관리, 저장
public/    브라우저 화면 (바닐라 JS, 빌드 없음)
test/      node:test 자동 테스트와 봇
scripts/   lint, 테스트 봇 클라이언트
docs/      규칙, 조사 기록, 진행 상황
```

서버가 차례·행동 유효성·난수·결과를 확정하고, 브라우저는 행동을 요청하고 서버가 보낸 상태를 표시합니다.
요청마다 `actionId`(중복 방지)와 `pendingId`(오래된 화면의 요청 거부)를 검사합니다.
