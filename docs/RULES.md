# 갈림길 인생 — 규칙 (자체 설계, v0.2)

모든 규칙은 `game/engine.js` 와 `game/content.js` 가 기준이며 이 문서는 요약이다.
금액 단위는 **만원(정수)**.

## 1. 진행 구조
성장기 → **진로의 문**(정지, 부족한 능력 1개 보완) → 갈림길(**캠퍼스 길**: 학자금 부채 120·학위·지성+1 / **사회 길**: 아르바이트 시작·현금+40)
→ **첫 직장**(정지, 직업 선택) → 성인 전반 → **인생 중간 점검**(정지) → 성인 후반 → **은퇴**(정지) → 전원 은퇴 시 최종 정산.

성인기부터 시작하면 전원이 동시에 **배경**(대학 졸업/체육 특기생/예술 전공/사회 경험파)과 **첫 직업**을 고른 뒤 성인 전반 출발점에서 시작한다.
성장기 시작이면 전원이 동시에 **어린 시절 성향**(능력 +2)을 고른다.
준비가 끝나면 모두 **순서 주사위**를 굴린다. 높은 숫자부터 시작하며 동점자끼리 자리가 정해질 때까지 다시 굴린다.

## 2. 한 턴
1. 현재 플레이어는 이동 전에 카드 사용·부채 상환을 할 수 있다. 성인기에는 생활 활동을 한 가지 고른 뒤 주사위를 굴릴 수 있다.
2. 주사위 1~6. 보정 순서: 정조준(값 고정) → 질주 +2 → 의욕 +1 → 번아웃 −1 → 자동차 최소 2 → 최소 1
3. 한 칸씩 이동
   - 갈림길: 선택을 기다린다(남은 이동 칸 수 유지). 길 선택 효과는 즉시 적용
   - **정지 칸**(관문·은퇴): 도착 즉시 멈추고 남은 이동은 소멸
   - 지나가는 칸: 월급날(월급), 용돈(+5)만 효과
4. 도착 칸 처리 → 사건 선택지 → 비용 지불 → 확정 효과 또는 판정 → 결과 표시(원인과 변화량)
5. 현재 플레이어가 결과를 확인하고 차례를 넘긴다. 상태 지속 턴을 줄이고 다음 플레이어가 시작한다. 이번 차례에 얻은 상태의 턴은 줄지 않으며, 은퇴한 플레이어는 건너뛴다.

판정: `주사위(1~6) + 능력 + 상태 보정 ≥ 목표`. 성공 확률 = clamp((7 + 보정 − 목표)/6). 선택지에 % 로 표시.
"운" 판정은 능력 보정이 없다.

## 3. 칸
사건·배움·놀이·창작·친구·행운·위기(사건 풀), 카드(1장), 용돈(지나가면 5, 멈추면 10), 월급날(지나가면 월급, 멈추면 +월급 절반·도전형 승진 판정),
직장(직업 사건), 인연(관계 사건), 마켓(자산 매매), 모두의 광장(공동 사건), 바람섬(특별 지역), 관문, 은퇴.
월급날은 주 경로 5칸마다 1개.

## 4. 직업 (총 14종, 추가 진로 켜면 +3)
| 계열 | 직업 | 승진 |
|---|---|---|
| 조건형 | 회사원, 공무원(실직 없음), 간호사, 교사(학위·실직 없음), 의사* | 지정 능력 합 ≥ 기준이면 월급날 자동 승진 |
| 도전형 | 운동선수, 뮤지션, 창업가(시작비 60), 크리에이터* | 직업 칸·월급날 도착 시 주사위+능력 판정. 직업과 직급에 따라 목표가 다르며 연속 2회 실패 시 강등 |
| 축적형 | 요리사, 개발자, 연구원(학위), 스마트팜 농부* | 성과(월급날 +1, 사건) 누적. 기준은 게임 길이에 비례(0.5~1.6배) |
| 자유형 | 아르바이트 | 조건 없음. 직장 칸에서 다른 직업으로 비용 없이 이동 |

- 전직: 교육비 30(추천서 카드면 면제·2단계 시작), 유지: 능력·카드·자산 / 상실: 직급 / 이월: 성과 절반
- 실직: 실업 급여 15 (최대 3회), 직장 칸 → 재취업 박람회, 아르바이트로 회복
- 운동선수는 성인 후반 은퇴 사건(코치 전직 또는 마지막 시즌)

## 5. 관계와 가족
- 인연·사건 칸이나 성인기의 **생활 선택**에서 소개와 데이트를 할 수 있다. 호감도 2 이상이면 연애를 시작하고 3 이상이면 프러포즈할 수 있다.
- 프러포즈는 사교+호감도 판정(목표 9)으로 결정한다. 결혼식 비용은 30이고 추억 +2와 월급날 배우자 수입 +10을 얻는다.
- 자녀는 최대 2명까지 맞이할 수 있다. 한 명당 월급날 양육비 6과 정산 보너스 60이 적용된다. 발표회와 가족 벼룩시장 등이 발생할 수 있다.
- 생활 선택에서 교육비 35를 지원하면 정산 보너스 +60을 얻는다. 자녀를 맞이한 뒤 자기 차례가 두 번 지나면 장학금 45에 지원하거나 취업 지원에 25를 내고 월급날마다 생활비 18을 받을 수 있다. 교육비 지원, 장학금, 취업 지원은 각각 한 번씩 가능하다.
- 반려동물의 월급날 비용은 2, 정산 보너스는 20이다.

## 6. 자산과 부채
- 순자산 = 현금 + 자산 평가액 − 부채
- 부채 한도 = 200 + (직업 있으면 60 × (직급+1)) + 자산 평가액의 절반
- 지출 > 현금 → 부족분 자동 대출 → 한도 초과면 평가액 낮은 자산부터 70%에 강제 매각 → 그래도 초과면 **신용 경고**(자산 구매 불가). 한도 이하로 회복 시 해제 + "오뚝이 인생" 업적
- 월급날 이자 = 부채 × 5% (올림). 내 차례 시작 때 언제든 상환 가능
- 마켓: 원룸(120, 수입 4), 아파트(380, 추억+1), 상가(260, 수입 16), 자동차(70, 이동 최소 2), 주식(60, 시장 사건 변동), 골동품(50, 정산 감정 0.2~4배). 매각은 평가액의 80%
- 생활 선택의 유료 활동에는 맞춤 과외, 휴식, 지역 행사 후원, 공연 데이트, 가족 사진과 여행이 있다.

## 7. 카드 (손패 최대 5장, 초과 시 가장 오래된 카드 버림)
| 카드 | 시점 | 효과 |
|---|---|---|
| 질주 | 내 차례 시작 | 이동 +2 |
| 정조준 | 내 차례 시작 | 이동 칸 수 1~6 지정 |
| 원데이 클래스 | 내 차례 시작 | 능력 +1 |
| 데이트 티켓 | 내 차례 시작 | 호감도 +1 (상대 필요, 실연 중 불가) |
| 응원 편지 | 내 차례 시작 | 다른 1명 다음 판정 +2 |
| 추천서 | 내 차례 시작 | 즉시 전직 상담(교육비 면제) |
| 오뚝이 | 현금 50 미만 또는 무직 | 현금 +80, 번아웃·실연 해제 |
| 다시 한 번 | 판정 실패 직후 | 재판정 1회 |
| 생활 보험 | 자동 | 다음 지출 사건 손실 절반 |
같은 카드는 한 차례에 한 번. 사용 불가 시 이유를 표시.

## 8. 상태
번아웃(이동 −1), 부상(체력 판정 −2), 실연(사교 판정 −1·데이트 불가), 영감(감성 판정 +2), 의욕(이동 +1), 응원받음(다음 판정 +2, 사용 시 해제), 신용 경고(해제 조건까지).
같은 상태는 중첩되지 않고 남은 턴을 더 큰 값으로 갱신.

## 9. 플레이어 간 상호작용과 많은 인원
- "모두에게 받기/주기" 총액 = 기준액 × min(상대 수, 3), 1인 금액 = 총액 ÷ 상대 수(내림, 최소 1). 받기는 상대 현금 한도 내.
- 공동 사건(모두의 광장): 전원 동시 선택, 모두 응답하면 도착한 사람부터 차례 순서로 적용. 은퇴자도 참여.
  - 축제 준비(목표 = 인원 × 12), 공동 펀드(배수 0.5~2 공통), 대동창회(참석자 수에 따라 보상)
- 뒤처진 플레이어 보정: 3인 이상, 순자산 최하위이고 1위와 200 이상 차이면 4턴마다 카드 1장
- 응원 편지로 다른 플레이어를 도울 수 있음
- 게임 화면의 **채팅**에서 방 참가자에게 메시지를 보낼 수 있다. **말풍선 표시**를 켜면 새 메시지가 내 보드에 잠깐 표시된다.

## 10. 동시 선택과 시간 제한
- 동시 입력은 성향·배경·첫 직업, 순서 주사위, 공동 사건에 사용한다. 해당하는 플레이어 전원이 응답하면 결과를 처리한다.
- 선택 시간은 기본 무제한이다. 방장이 30/60/120초를 설정하면 시간이 끝난 단계의 기본 행동을 적용한다. 결과 확인 시간이 지나면 차례를 자동으로 넘긴다.
- 시간 제한이 없어도 대기 중인 사람이 60초 이상 연결이 끊기면 다른 참가자가 "자동 진행" 가능

## 11. 종료와 정산
- 은퇴 칸 도착 순서 보너스 150 / 100 / 60. 은퇴자는 차례를 건너뛰지만 공동 사건·타인 효과는 계속 받음
- 전원 은퇴 시 정산: 현금 + 자산(골동품 감정) − 부채 + 은퇴 순위 보너스 + 배우자 100 + 자녀 60(+30 학원) + 반려동물 20 + 추억 × 15 + 최종 직급 × 40 + 업적(올림피아드 30, 첫 메달 30, 반장 30, 특허 50, 마지막 시즌 50, 오뚝이 80, 달인 40)
- 동점: 총점 → 현금 → 먼저 은퇴한 순
- 결과 화면에 단계별 정산표와 인생 기록. 방장이 "같은 멤버로 다시 하기"로 대기실 복귀

## 12. 길이 설정
| 프리셋 | 시작 | 성장기/전반/후반(칸) | 콘텐츠 |
|---|---|---|---|
| 짧은 여정 | 성인기 | -/16/16 | 공동 사건 |
| 기본 여정 | 성장기 | 16/25/23 | 추가 진로·공동 사건·확장 사건 |
| 긴 여정 | 성장기 | 25/36/34 | 전부 |
범위: 성장기 8~30, 전반·후반 10~40. 1인 예상 턴 = (칸 수 + 관문·갈림길 보정) ÷ 3.4.
콘텐츠 의존: "확장 사건" 중 의대 편입 사건은 "추가 진로"가 켜져 있을 때만 등장(`requires`).

## 13. 사건 데이터 형식 (`game/content.js`)
`id`, `spaces`(칸 종류), `stages`, `pack`, `requires`, `when`(발생 조건), `weight`, `once`/`cooldown`(재발생), `chainOnly`,
`title`/`text`, `options[]`: `label`, `cost`, `when`, `effects` 또는 `check{stat,target}`+`success`/`fail`, `promoCheck`, `buy`, `next`(후속 사건), `default`(시간 초과 기본값).
최근 6턴 안에 본 사건은 가중치 0.3배.
