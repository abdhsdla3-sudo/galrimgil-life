# 진행 상황 (2026-11-18 기준)

## 기술 선택과 가정
- 저장소가 비어 있어 **Node.js 단일 서버 + 바닐라 JS 클라이언트**로 시작. 외부 패키지 0개(빌드·설치 불필요).
- 실시간 동기화: **Server-Sent Events + HTTP POST**. 웹소켓 라이브러리 없이 HTTPS 프록시/호스팅에서 그대로 동작.
- 저장: 방마다 JSON 파일(임시 파일 쓰기 후 이름 변경). 12명·수백 KB 수준이라 DB 불필요.
- 규칙 엔진(`game/`)은 시간·`Math.random`을 쓰지 않는 결정적 상태 머신. 난수 상태를 게임 데이터에 함께 저장.
- 린트: 의존성 없는 `scripts/lint.js`(구문·UTF-8·콘텐츠 무결성). **타입체크는 TypeScript가 없어 미설정**(의존성 추가 금지 원칙).
- 배포 대상: 영구 디스크가 필요한 단일 컨테이너 → Fly.io(권장)/Render 유료/내 PC + Cloudflare 터널.
