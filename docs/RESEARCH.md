## 2. 항목별 정리

- [공식] 아기 → 초등 → 중등 → 고등 → 어른 전반 → 어른 후반 → 마지막 시대의 7구간 이미지(타카라토미).

- [관찰] 침착맨 편집본 챕터: 아기 04:27 / 초등 12:10 / 중등 20:12 / 고등 30:14 / 성인 초반 44:56 / 성인 후반 1:41:16 / 황혼기 2:33:33 / 결과 발표 2:52:46. 편집본 기준 성장기 약 40분, 성인 전반 약 56분, 후반 약 52분, 황혼기 약 19분(4인).

## 3. 자체 설계로 결정한 부분
